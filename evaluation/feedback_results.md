## Themes from open-ended answers

| Theme | Respondents | What we changed |
| --- | --- | --- |
| Parallel coordinates: focus and clutter | 8 (F1, F4, F5, F7, F8, F9, F12, F13) | Selected tract drawn bold with value labels, highlighted lines in front, five measure presets, line legend, labelled focus axis, hover shows exact values |
| One connected story across the views | 7 (F3, F4, F6, F8, F10, F11, F13) | Overview tab that maps the question to each view; guided story rebuilt around one question and one tract, with transitions and a recap |
| In-context explanations of charts | 4 (F3, F6, F11, F12) | "How to read" notes on parallel coordinates, whiskers, peers and the care-gap legend; plain-language tooltips |
| Save, export or share a view | 4 (F3, F5, F6, F13) | Download CSV, printable summary report, PNG export with caption and source, shareable links that keep the selection |
| Color contrast and legend size | 4 (F4, F7, F9, F12) | High-contrast option for groups and lines; larger legend text |
| Where to start / too much at once | 3 (F2, F9, F12) | Overview tab with five quick-start questions and one primary next step |
| A practical outreach example | 2 (F5, F9) | Story follows a real outreach question; recap card with a downloadable outreach list |
| Data source and update date | 2 (F1, F4) | Data source, release and refresh date shown in the header and Overview; fresh-data workflow on GitHub Actions |
| Explain uncertainty and methods | 2 (F8, F11) | Uncertainty legend beside the profile, methods & limitations panel, exact CI in tooltips and exports |
| Make cross-view linking obvious | 2 (F5, F7) | Persistent "following" bar, same tract outlined in every view, link captions on every card |
| Explain how similarity is computed | 1 (F10) | "What does similar mean?" panel and plain-language similarity labels |
| Compare a few chosen areas side by side | 1 (F9) | Pin up to 4 tracts and compare them in one table |
| Finding a county by name | 1 (F8) | Search box labelled "Find a county, town or tract" and the / shortcut |
| Exact values for an outlier | 1 (F7) | Hover on any line or dot shows exact values with CIs |
